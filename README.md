# Sanctuary App

A secure, AI-enhanced journaling and relationship tool built with Next.js, Supabase, and Tailwind CSS.

## Getting Started

1. Install dependencies:

```bash
npm install
```

2. Setup your `.env.local` using the provided `.env.example`.

3. Run the development server:

```bash
npm run dev
```

## Scripts

- `dev`: Start development server
- `build`: Build for production
- `lint`: Run ESLint

## Technologies Used

- Next.js 14
- Supabase
- Tailwind CSS
- HuggingFace Transformers
